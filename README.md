## Run a task

```bash
git clone https://github.com/amiirofahad4-ai/codealpha_tasks.git
cd codealpha_tasks/Task1_FlashcardQuizApp   # or another task folder
```

- **Tasks 1–3 (React Native / Expo):** `npm install`, then `npx expo start`, and scan the QR code with Expo Go.
- **Task 4 (Flutter):** `flutter pub get`, then `flutter run`.

Task 3 needs a free Supabase project; see its README for the two-line `.env` setup.
